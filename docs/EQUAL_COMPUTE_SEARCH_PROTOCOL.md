# Equal-compute allocation search: implemented baselines and next KWS study

`netsurf/equal_compute_search.py` implements two distinct mask-selection policies over a fixed candidate universe and cardinality. `random_search` draws a uniform legal fixed-budget mask with replacement for each proposal and retains the lowest measured selection risk. `greedy_swap` starts at the same mask, samples one protected and one unprotected coordinate uniformly, and accepts only a strict measured risk reduction. Both spend one query on the common initial mask and then the same prespecified number of proposals. Ties retain the incumbent. Seeds, proposal traces, risk values, accepted states, query counts, evaluation cost and wall time are recorded. The callback supplied by a real benchmark must use the same frozen input cohort and master fault fields for every query. Held-out evaluation requires a distinct field/input identity and never feeds risk back into search. A random search that selects the best measured mask is therefore separate from a single random-ranking baseline.

The pure search layer has deterministic pseudo-Boolean tests for signed effects, a pair interaction, initial-mask equality, fixed budget, matched query counts, independent final identity, reproducibility, and a meaningful 72-bit/24-protected scaling fixture. It does not implement RL or a guided optimizer.

### Cost and inference scope

Six search trajectories × 64 queries × 64 selection fields require **24,576 mask/model requests** and **1,572,864 clip inferences**. The 72 isolated-bit calls plus one clean call add 73 requests and 4,672 clip inferences. Final evaluation has 128 × 8 = **1,024 requests** and **425,984 clip inferences**. The complete frozen envelope is **25,673 requests and 2,003,520 clip inferences**, plus adapter initialization/reference overhead. Historical M9.6 measured 24,660 selection requests, 1,578,240 selection clip inferences and 5,840.14 s across 12 members; its final members took 7,461.99 s for a much larger 9,437,184-clip upper bound. These are reference measurements, not a throughput guarantee for the new search. Provision about **3 foreground hours and at least 2 GiB RAM** initially; the bounded two-clip adapter check verified receipts but is not a throughput benchmark. If execution is slower, stage the already-frozen selection and revise only the operational time reservation. The 64 candidate-fault fields may yield unstable or null selection at p=0.01; field counts and hypotheses must not be raised after seeing final effects.

The prespecified primary contrast is the paired final cross-entropy difference **greedy minus random**, averaging the three fixed proposal seeds within each final field; negative favors greedy. Use a two-sided 10,000-replicate field bootstrap interval and 10,000 paired sign-flip draws at analysis seed `970901`, with no grid search. The secondary family has exactly four two-sided contrasts: random minus S5, greedy minus S5, random minus isolated, and greedy minus isolated, each averaged over its three seeds; apply Holm adjustment across those four sign-flip p-values. Preserve all six seed-specific masks and effects in sensitivity tables. Report accuracy separately, favorable/adverse/tied field counts, median and 10% trimmed field differences, maximum absolute field difference, nonfinite/failure counts and the effect after omitting the largest absolute field as heavy-tail diagnostics. The single fixed 72-bit panel supports inference conditional on that panel and final input cohort; its 12 historical K=6 components are **not** independent cross-pool replicates for this global search. Shared final clips and fault fields preserve dependence among all policies. No whole-model optimality, cross-pool generalization or physical reliability claim follows.
