# Frozen, targeted 96-bit Pythia/Qwen protection studies

These are **prospective, unexecuted, targeted** language-model studies. They are separate from the completed 32-token engineering smokes and from any full-model reliability claim. The scientific source was frozen at commit `d8d3ba1`; the Kona READY snapshot is SHA-256 `3192d3ce57b7a11089af4c1e0f802e851ebc8b179fd823a793fecf333313db35`. The original and derived Pythia runtime configurations are distinct plans. Native BF16-computation Pythia remains validation failed and has no plan.

| `pythia160m_bf16stored_fp32compute` | `9d20067254f632cf5f93650a1980c6755847fa241be56e8e19a45975b6ae6043` | 1,977,090,048 | BF16 encoded XOR → verified, separately allocated FP32 execution copy |
| `qwen3_0_6b_bf16` | `f41e841bed8510a55378c3a3b738d1b221c1752f2ae2eb69197bab6bc6392573` | 7,046,430,720 | BF16 → BF16 |

Each plan selects 32 distinct scalar words uniformly without replacement from the verified contiguous `nn.Linear.weight` universe using Python `Random(991001)`. It fixes the sign bit, highest exponent bit and high significand bit of each word, for 96 exact encoded coordinates. There are 32 bits of each class. The full eligible linear-weight count and descriptor digest are recorded, but the Bernoulli law applies **only to these 96 declared candidates**. Embeddings, norms, biases, tied weights, all other linear bits and other model state are outside this experiment. The two Pythia plans select the same scalar-word ordinals in their corresponding checkpoints, with precision-specific bit positions; they do not imply equal fault severity.

## Inputs, policies and statistical family

Selection scores use WikiText-2 raw **validation** token IDs 33–160 (127 scored target tokens), disjoint from the first 33 validation IDs used in engineering smokes. The final evaluation uses **test** token IDs 0–256 (256 scored targets); Kona's historical clean reference is disclosed, while these IDs have no NetSuRF fault-outcome exposure in the inspected run directories. The complete token sequences, bounded slices, tokenizer, dataset, checkpoint, runtime, source and READY entry are hash-bound in each plan. Evaluation is deterministic teacher forcing with no BOS/EOS insertion, one window of at most 257 IDs under the pinned 1,024-token context/512 stride, CPU eager attention and no training behavior. Qwen's tokenizer can warn while tokenizing the complete raw text that its sequence exceeds the model context; the actual inference slice is 257 IDs, within the validated context.

The three selection methods are a fixed random ranking, stored-position significance, and exact isolated-bit task-loss damage on the validation slice. Only the isolated method makes selection model calls. At budgets 12 and 24, each method selects its own mask; unprotected and full logical protection are controls. Signed isolated scores are retained. All three methods and every isolated member must seal before any final field. There is no Hessian, gradient or guided optimizer arm. Each final master field is shared across the eight policies, and all policies use the same test tokens. Separate final seeds are fixed by `130001 + 100000 × BER_arm + field_index`, with 32 fields at each nonzero BER. Sampled fields are exact independent Bernoulli over 96 candidates with a fail-closed event cap, not forced fault patterns.

The grid is `p = 0, 1/96, 4/96`, chosen from expected *candidate-panel* unprotected exposures λ=0, 1 and 4. At budget 12, expected applied faults per field are 0.875 and 3.5; at budget 24, 0.75 and 3.0; at full protection, zero. These BERs must **not** be copied to the multi-billion-bit full universe. The primary two-sided family is exact isolated versus significance at `p=4/96` for budgets 12 and 24, Holm-adjusted across two. All eight exact-isolated versus random/significance contrasts across the two BERs and two budgets receive a separate Holm adjustment as secondary analysis. Fault fields are stochastic replicates; the same token cohort across fields and BERs is not independent token replication. Per-field paired means, percentile bootstrap intervals, sign-flip p-values, favorable/adverse/tied field counts, median and maximum absolute differences, capped mean NLL, perplexity and failed-token fractions are saved. The 30-nat per-token penalty is fixed before evaluation. No grid search for a smallest unadjusted p-value is allowed.

## Exact work and resource envelope

Each target requires 97 selection requests (one clean, 96 isolated), then 513 final requests (one clean, 32 fields × two nonzero BERs × eight policies): **610 model requests**. The exact scored-target count is 12,319 in selection plus 131,328 in final, or **143,647 scored target requests**. Input-token positions, including the initial context token, are 12,416 in selection and 131,841 in final. These counts assume no interrupted field; a partial field is retained as an immutable intent and blocks automatic restart. Verified complete fields resume without inference. An operator must audit a partial intent before any same-identity recovery; the one-shot script does not silently change seed or cohort.

One clean 257-token test call was measured under the pinned CPU environment: Pythia FP32/FP32 0.205 s and 1,583 MiB peak RSS; Pythia BF16/FP32 0.724 s and 1,838 MiB; Qwen BF16 1.321 s and 2,044 MiB. These are **clean-call timing checks**, not fault-campaign throughput or scientific effects. The finalized ten-request fault smokes took 31.08 s/1,362 MiB, 37.88 s/1,984 MiB and 15.00 s/2,044 MiB, respectively, including model load, byte verification and restoration. Provision at least 4 GiB RAM and one hour for each Pythia target, and 6 GiB RAM and two hours for Qwen as conservative foreground planning envelopes. Timing may differ substantially with faulted numerical behavior. These are planning estimates, not a formal power calculation.

The targeted campaign code has an end-to-end synthetic test covering selection, sealing, final fields, verified resume, paired analysis and ZIP export. Each frozen real-model plan has been validated against the actual READY model, source, bit population and token identities without running selection or final fault inference. Because no prospective targeted final has run, no Pythia/Qwen effectiveness row or figure is eligible for the manuscript yet. A future full-model study still needs a scalable, scientifically justified protection budget and selector, plus its own fresh exposure design.
