**First delivery gate — 2 November 2026. Not a replacement manuscript.**

The engineering question worth retaining is: **How reliably can static encoded-bit
susceptibility rankings guide resource-constrained protection of quantized neural
networks under simultaneous parameter faults?** The evidence supports an internal
draft of that investigation now. It does **not** support restoring the original
qPolarGrad-superiority, physical-resource savings, or optimal-allocation claims.

## 4. Numerical and hardware consistency findings

### 4.1 Exact encoding, delta matrices and physical population

For signed INT8 code `q`, unsigned word `u=q mod 256`, bit `k` (LSB=0), and
decoded value `w=s(q−z)`, define

`delta_b = s * (signed8(u XOR (1 << k)) − signed8(u))`.

For k<7 this is `s(1−2u_k)2^k`; for the sign bit it is
`−s(1−2u_7)128`. The zero point cancels in the difference; channel scale does not.
Example at s=1/16, z=0: code −3 is `11111101`, decoded −0.1875. Flipping bit 0
gives −4 and delta −0.0625; flipping bit 7 gives +125 and delta +8. This explains
why small parameter magnitude does not imply small encoded-bit sensitivity.

Original Eq. (3), `(-1)^(W[k]) 2^k`, omits the sign-bit reversal and physical
scale and uses a different index convention from Fig. 1. Under QKeras's audited
six-bit/two-integer-bit signed interpretation, spacing is 1/8, unlike Fig. 1's
1/32. Both formats can be meaningful; they are not the same experiment.

The modern fault population includes allocated zero kernels; a zero-valued word
can become nonzero after a flip. Nonzeros are not a physical storage count.
All three main benchmarks exclude INT32 bias codes, activation buffers and affine
metadata. Frozen metadata is part of the execution contract, not protected for
free in a claimed physical implementation. Exact distinct-bit jumps add within
a word, but task risk remains nonlinear and repeated flips on one bit cancel.

`O(c)=c(C_100/C_0−1)`; hence `c_max=min(1, B/(C_100/C_0−1))` for an overhead
budget B relative to the unprotected design.

## 5. qPolarGrad: three distinct contracts, no silent repair

1. **Recovered historical implementation.** For dense kernel bit b, approximately
   `abs(mean_x(attacked_input_i(x) * delta_b) * mean_loss_gradient_i)`.
   `QPolarWeightRanker` first applies an all-bit attack; downstream activation
   factors are from that corrupted model. `QPolarGradWeightRanker` multiplies the
   resulting impact by a gradient score. Mutable attack state could accumulate
   across calls. v2 `legacy_qpolargrad`, version `recovered-dense-first-call/v1`,
   preserves the first-call formula with deterministic inputs, not contamination.
2. **Printed expression.** Eq. (7) writes `P * gradient^T * delta_theta`, while
   Table I already gives dense `P=delta*X`. Taken literally, delta appears twice;
   reduction, absolute value and clean/attacked activation conventions are not
   completely specified. It is not the same executable score. No paper-form
   replacement was implemented in this audit.
3. **Separately named candidates.** `clean_activation_qpolargrad`
   (`clean-dense-mean-cancelled/v1`) substitutes clean inputs.
   `uncancelled_activation_drift` (`clean-dense-mean-absolute/v1`) aggregates drift
   magnitudes before cancellation. They are hypotheses, not accepted corrections.

The gradient already contains the layer input through the chain rule. Multiplying
another input/drift factor does not automatically estimate loss change, and signed
averaging can cancel. Different scores also need not produce different masks.
Calling the method O(N) in parameter count does not account for calibration-set
size, forward/backward work, layer shape or activation storage; the historical
runtime/speedup observations are not reproducible v2 construction-cost claims.
Source anchors: `DEPRECATED/legacy_source/netsurf/core/ranking.py`, classes
`QPolarWeightRanker` / `QPolarGradWeightRanker`; `netsurf/estimators_m3.py:qpolargrad`;
`docs/LEGACY_ESTIMATOR_RECONSTRUCTION.md`.

**Decision:** preserve historical qPolarGrad as an explicitly scoped dense-network
ablation or historical explanation. Do not build Paper 1's principal contribution
around it. There is neither validated MLPerf qPolarGrad coverage nor fair evidence
that it beats corrected MSB/FKeras. Modern first-order results are not evidence for
the historical equation. An additional estimator identifier would require a new
scientific definition and validation, not editorial renaming.

## 6. Reconstructed central claim

**NetSuRF provides an encoding-aware evaluation flow for selecting and auditing
static protection masks under a fixed logical bit budget. On three frozen INT8
edge-inference models, it connects exact stored-code faults, inexpensive ranking
proxies, matched simultaneous-fault trials and task-level quality curves. The
results show that the benefit of a ranking depends on architecture, task, BER and
budget: gradients can materially improve some allocations, but neither isolated
damage prediction nor a sophisticated score guarantees deployment benefit.
Exact bounded-candidate diagnostics explain how background faults change marginal
vulnerability, while held-out results limit claims about the size and generality
of allocation regret. The contribution is a controlled engineering evaluation and
decision-validity methodology—not universal optimizer superiority, a new Boolean
theory, or experimentally validated physical hardening.**

The exact identities underpin, rather than displace, that narrative. With
`J_p(P)=E[R(F\P)]` and G excluding b and protected coordinates,
`J_p(P)−J_p(P∪{b})=p E[R(G∪{b})−R(G)]` under independent Bernoulli faults.
The clean isolated effect is a different quantity. As a bounded analytical
counterexample, set R(empty)=0, R(a)=.2, R(b)=.1, R(c)=0, R(ac)=0,
R(bc)=.9, R(ab)=.3, R(abc)=.5. Protecting one of a or b gives
`J(protect a)=.1p+.8p²`, `J(protect b)=.2p−.2p²`: isolated ranking prefers a,
but protecting b is better for p>.1. All eight risks are in [0,1]. This is a
mathematical possibility, not a trained-network performance claim. A static
deployment mask may still be optimal; a context-independent ordering has no
universal guarantee. Beneficial faults are not clipped away.

Edge Neural Networks.”** This is a scoped variation of option C, retaining the

**C**. A sounds rhetorical; B can imply a deployed beyond-static optimizer whose
