# NetSuRF internal-review manuscript

Root document: main.tex. Compile with latexmk -pdf -interaction=nonstopmode -halt-on-error main.tex using the installed ACM acmart class. The source ZIP is directly importable into Overleaf; choose main.tex and pdfLaTeX. Numerical figure PDFs are included under figures/ in that ZIP. In the repository they are also available one directory above source/.

This is a complete software-only internal draft, not a submission-ready manuscript. It preserves the supplied ACM project and engineering narrative, replaces unfinished result sections with finalized evidence, and restores the four historical authors. Authorship, corresponding-author designation and disclosure must be confirmed by the researchers before submission. The review format deliberately omits the ACM reference block; its class warning is expected and should be resolved at submission according to venue instructions.

The current evidence includes six full-eligible INT8 benchmarks, published-form FKeras on three of them, independent-field follow-ups, and the unresolved 32-pool conditional-versus-exact-isolated comparison. See the complete review ZIP for claim-to-evidence mapping, figures/data, original-paper audit, venue assessment and remaining scientific risks. There are no placeholder results. No new inference was run to prepare this manuscript.
