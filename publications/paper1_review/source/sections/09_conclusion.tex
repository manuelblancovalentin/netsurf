\section{Conclusion}\label{sec:conclusion}
We compared seven static bit rankings as equal-budget protection masks on six frozen INT8 models. Where the model is still useful, the choice of ranking decides how far the fault rate can rise, and the per-example absolute-gradient ranking is a strong default among those measured, including when calibration inputs, masks, input windows and pruned checkpoints change. It is not a universal answer. Significance-first protection falls further behind the more marginal the checkpoint; on an under-trained checkpoint the preferred ranking reverses inside the useful band; and a ranking that protects only flips predicted to raise the loss can be worse than no protection, because the faults it leaves push the weights one way. At dense fault rates, triplicating ranked bits outperforms blanket codes and checksum correction of equal storage. These results hold under ideal logical protection, for one trained checkpoint per model apart from the ResNet-8 variants, and leave open how search-based or learned allocators compare when the fault rate is uncertain.
