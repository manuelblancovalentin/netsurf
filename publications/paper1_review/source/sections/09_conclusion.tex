\section{Conclusion}\label{sec:conclusion}
We compared static bit rankings as equal-budget protection masks on six frozen INT8 models. Where the model is still useful, the ranking decides how far the fault rate can rise. The per-example absolute gradient is a strong default: with 64 calibration inputs it holds across masks, inputs, pruned checkpoints and retrained copies, no tested search or literature-derived allocator beats it on ResNet-8, and with up to 1,024 calibration inputs it trails no gradient ranking there by more than 2.5 points where the model is usable. No fixed ranking is best everywhere: significance-first protection falls far behind on every checkpoint, the ranking that wins where faults are sparse loses badly where they are dense, and protecting only loss-increasing flips can be worse than none. At dense fault rates, triplicating ranked bits outperforms blanket codes and checksum correction of equal storage. All results assume ideal logical protection.
